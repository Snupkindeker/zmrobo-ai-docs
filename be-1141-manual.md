### (2) Баланс белого

Поскольку сенсор определяет цвета не так, как мы их воспринимаем, он может быть более чувствителен к определенному цвету и реагировать на него пропорциональным отклонением от значений трех первичных цветов RGB. Поэтому необходимо выполнить обработку баланса белого на датчике, чтобы он знал, что такое белый цвет, т.е. привести соотношение трех первичных цветов RGB к одинаковому. Модуль имеет встроенную функцию автоматической обработки баланса белого, команда для выполнения автоматического баланса белого - 31, операция выполняется следующим образом:

Установите датчик на расстоянии около 10 мм над белой бумагой (пока она белая, учитывайте, что отражающая поверхность имеет рассеянное отражение), отправьте через контроллер команду 31 (автоматический баланс белого), датчик выполнит обработку баланса белого - он обработает текущий цвет как белый и автоматически сохранит значение шкалы обработанного баланса белого. С помощью команд 12-14 можно считать значение пропорции при обработке баланса белого. Команды 1-3 позволяют считывать данные о трех основных цветах RGB после обработки баланса белого. По умолчанию диапазон этих трех возвращаемых данных составляет 0-100. После обработки баланса белого значение трех основных цветов RGB будет рассматривать текущий цвет как белый и подгонять данные о цвете после баланса белого к 100. Если подгоняемое значение RGB не равно 100, можно выполнить обработку баланса белого несколько раз для достижения наилучшего эффекта.

Если эффект автоматической обработки баланса белого неудовлетворителен, можно также вручную изменить значение коэффициента баланса белого, команда 34-36. подробные команды управления приведены в Таблица 3. Список управляющих команд.

Примечание: Баланс белого не повлияет на внутреннее распознавание цвета, он повлияет только на возвращаемое значение команды 1 ~3.

### (3) Режим расширения цветовой гаммы

Режимы расширения цветовой гаммы позволяют модулям адаптироваться к более сложным условиям окружающей среды. Обучение цвету — это режим расширения цвета, с помощью которого модуль может корректировать изменение цвета. Для выполнения обучения цвета модуль переходит в режим расширения цвета.

## ① Обучение цвету

Обучение и адаптация, которые модуль выполняет при сканировании, когда цвет имеет различные уровни вариаций. Процесс изучения цвета на самом деле представляет собой пороговое значение (то есть эталонное значение), разделяющее различные изменения яркости известных цветов (то есть изменения глубины цветов). Командой входа в режим обучения цвета является 42, и после входа в режим обучения модуль не может выполнять никакую другую работу до тех пор, пока не получит команду 43 - End Learning. Операции для выполнения обучения цвету следующие:

Зафиксируйте модуль на определенной высоте над сканируемым цветом и отправьте через контроллер команду 42 (Обучение цвету), после чего вы увидите, что индикатор модуля мигает с определенной частотой, что свидетельствует о переходе модуля в режим обучения цвету. Поместите модуль на область, которую необходимо просканировать и просканируйте область изменения цвета. Сканирование завершено, отправьте команду 43 для завершения процесса обучения цвета, в это время модуль потемнеет примерно на 1 секунду, автоматически сохранив опорное значение цвета, обучение цвета завершено. После обучения цвету, когда цвет будет выучен, результат распознавания будет изменен, считайте результат распознавания, для одного и того же цвета результат распознавания более темного цвета (т.е. меньшей яркости) будет увеличен на 10, а результат распознавания более светлого цвета (т.е. большей яркости) будет возвращен к исходному результату распознавания (см. ниже "Режим расширения цвета"). Вы можете повторно считать контрольное значение для изучения цвета с помощью команды 61-66. Если результат распознавания окажется неудовлетворительным, можно повторить описанные выше действия.

Функция обучения цветам запоминает только те цвета, которые в данный момент распознаются модулем, и не обрабатывает другие цвета.

## ② Изменение цветового расширения

В режиме обучения цвета модуль сам изучает окружающую обстановку и сохраняет эталонные значения цвета, которые могут быть считаны командами 61-66. Эталонные значения цвета в режиме расширения цвета измеряются в терминах яркости, и результаты распознавания, меньшие, чем эталонное значение яркости, будут возвращены путем сложения с 10 (11-16), а исходное значение результатов распознавания, большее, чем эталонное значение яркости, будет возвращено (0-6), поэтому единственная цифра результатов распознавания фактически все еще отражает исходные результаты распознавания текущего модуля. С помощью команды 17 можно считать значение яркости. Если после обучения цвета результат не удовлетворяет, можно изменить опорное значение, задав команды 46-51.

Режим расширения цвета может быть изменен вручную (состояние сохраняется после выключения питания), команда запуска режима расширения цвета - 44 (если выполняется обучение цвету, режим расширения цвета включается автоматически), команда выключения режима-45, которая заключается в однократном дифференцировании яркости поверх исходного результата распознавания цвета, а возвращенный результат делится на установленное опорное значение цвета в качестве разделительной линии. Возвращаемый результат делится на заданное

опорное значение цвета в качестве делителя. Подробные команды управления приведены в Таблица 3. Список управляющих команд

### (4) Пороговый режим черно-белого цвета (эталонные значения черно-белого цвета)

Из-за различий в датчиках распознавание модулем черного или белого может отличаться. При установке эталонного значения черного или белого цвета выполняется предварительная обработка распознавания цвета. Когда включен режим черно-белого порога, если были установлены опорные значения черного и белого, то в процессе распознавания цвета модуль сначала обработает значение яркости, и значение яркости, превышающее пороговое значение белого, распознается как белое, а значение яркости, меньшее порогового значения белого. пороговое значение черного цвета распознается как черный. Если эти условия не установлены, будет выполнено обычное распознавание. Команда для включения этого режима равна 54, а команда для выключения этого режима равна 55. Контрольное значение черного/белого может быть установлено с помощью команды 52-53. Следует отметить, что пороговое значение белого должно быть больше порогового значения черного. В противном случае, даже если оно установлено, режим недопустим. Команда 67-68 может считывать обратно исходное значение. Подробные команды управления приведены в Таблица 3. # 5. Советы по применению и меры предосторожности

Датчик устанавливается лицевой стороной вниз и не должен находиться слишком высоко от земли - оптимально 8-10 мм, следует избегать сильного освещения. Цветная отражающая поверхность должна быть рассеянной, чтобы обеспечить наилучшие результаты работы модуля.
