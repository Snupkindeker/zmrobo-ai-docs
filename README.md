# ZMROBO AI Docs

## Overview

This is an unofficial documentation for ZMROBO, that's meant to be used by AI to be more competent in this topic. By using this documentation, language models can help their users to:
- Choose best parts for their robots/builds.
- Write code in RoboEXP.
- Run RoboEXP's compiler from a terminal.
- Answer questions based on Super AI SuperTrack competition rules.
