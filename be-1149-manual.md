## 3) Функция SetTraceV2I2C (функция настройки подсветки)

(1) Описание функции: изменяет цвет подсветки на каждом датчике. Различные цвета отличаются отражательными способностями (меняется диапазон измеряемых значений) на разных поверхностях, поэтому лучше всего использовать различные цвета для различных цветов. Необходимо использовать интерфейс I2C.
(2) Значок функции:
(3) Описание параметров: Port Порт подключения Ch1 - Ch7 Значения цвета для каждого датчика. Подробнее см. таблицу цветов
(4) Таблица цветов:

|Номер||Каналы (R, G, B)||Итоговый цвет|
|---|---|---|---|---|
||Красный (R)|Зеленый (G)|Синий (B)||
|1|0|0|1|Синий|
|2|0|1|0|Зеленый|
|3|0|1|1|Голубой|
|4|1|0|0|Красный|
|5|1|0|1|Пурпурный|
|6|1|1|0|Желтый|
|7|1|1|1|Белый|

Примечание: 1 – означает яркий, 0 – потухший

# 5) Функция SetTraceV2PercentI2C (ручная установка порогового <u>процента</u>)

(1) Описание функции: в процессе настройки модуль считывает максимальные и минимальные значения отражающих значений на поверхности. Эта функция обеспечивает возможность корректировки общего значения отражающих значений модуля..
(2) Значок функции:
(3) Описание параметров: port Порт подключения molecular Числитель <u>denominator</u> Знаменатель Установите общий пороговый процент для модуля линии, процент = числитель/знаменатель. Например, если вам нужна треть значения между максимальным и минимальным значениями, напишите 1 для числителя и 3 для знаменателя.
