# Модуль измерения ориентации BE-2625 v2.0 Руководство пользователя

# 1. Краткое описание

Модуль измерения ориентации BE-2625 представляет собой систему отсчета ориентации и азимута, предназначенную для роботов. Помимо прямого вывода углов Эйлера, он обеспечивает измерение ускорений и угловых скоростей в трех осях XYZ, что дает преимущества интуитивно понятного и простого использования.

Области применения: балансировочные автомобили, подвесы, пульты дистанционного управления, роботы с несколькими степенями свободы, оборудование распознавания жестов, самолеты, подводные лодки и многое другое.

Описание

BE: указывает на электронную часть блочного робота 26: указывает на тип измерения – ориентация 25: указывает на I2C выходные данные об ориентации

# 2. Характеристики

1. Широкий диапазон рабочего напряжения: 4.5 … 5В
2. Частота обновления: 400HZ
3. Режим связи: I2C
4. Интерфейс модуля: универсальный интерфейс телефонной линии Zhongming RCU
# 3. Инструкция по эксплуатации

**1) Принцип работы** Модуль измерения ориентации BE-2625 объединяет данные собственного встроенного 3-осевого акселерометра и 3-осевого гироскопа, фильтрует выходные данные, затем интегрирует угол поворота по угловой скорости гироскопа со временем, корректирует его по 3-осевому ускорению и в итоге получает угол крена, угол тангажа и угол рысканья. Из-за отсутствия векторной привязки в горизонтальной плоскости нормальным является дрейф угла рысканья Yaw. Контроллер считывает эти данные по интерфейсу I2C.
**2) Установка оборудования** Подключите датчик ориентации к любому из портов P1 - P8 контроллера E6-RCU или в порты P1- P5 контроллера M5-RCU. Датчик должен быть установлен в горизонтальном положении.

### 4) Описание параметров

### Считывание данных:

(1) Угол Эйлера: ① Угол крена (Roll): угол поворота вокруг оси X; ② Угол тангажа (Pitch): угол поворота вокруг оси Y; ③ Угол поворота (Yaw): угол поворота вокруг оси Z
(2) Ускорение по трем осям: ① AccX: ускорение в направлении оси X; ② AccY: ускорение в направлении оси Y; ③ AccZ: ускорение в направлении оси Z.
(3) Угловая скорость по трем осям: ① GyroX: угловая скорость вокруг оси X; ② GyroY: угловая скорость вокруг оси Y; <u>③ GyroZ: угловая скорость вокруг оси Z.</u>

### Функция сброса:

(1) Однократная калибровка горизонтальной ориентации: в случае ошибок установки или ошибок горизонтальной плоскости в условиях использования можно использовать эту функцию для обнуления компенсации и повторной калибровки акселерометра и гироскопа, чтобы сделать ориентацию более стабильной (рекомендуется использовать в диапазоне менее -+10°).
(2) Восстановление заводских настроек.
# 5. Меры предосторожности при использовании

(1) После включения питания датчик AHRS должен находиться в горизонтальном положении в течение примерно 8-10 секунд, пока индикатор не перестанет мигать, после чего данные будут находиться в наиболее стабильном состоянии, также рекомендуется использовать функцию настройки после этого времени. (8 секунд не обязательно, но данные относительно стабильны, особенно угол рысканья Yaw)
(2) Углы крена и тангажа корректируются вектором ускорения по оси XYZ, поэтому погрешность точности мала. Однако угол рысканья Yaw определяется путем интегрирования гироскопа только по оси Z, и в нем отсутствует коррекция геомагнитометра, поэтому имеет место явление дрейфа. Как правило, более точным является значение в диапазоне -+90. При многократном вращении Yaw будет наблюдаться кумулятивная погрешность, поэтому используйте ее в соответствии с реальной ситуацией.
(3) Угол Эйлера имеет свои ограничения. Угол продольного наклона вблизи 90 градусов будет выглядеть странно, возникает сингулярность, то есть явление тупика карданного подвеса, которого следует избегать, насколько это возможно, при его использовании. Для получения более подробной информации обратитесь к соответствующей информации, здесь мы не будем вдаваться в подробности.
(4) Возвращаемое значение переменной чтения -16-разрядное целое знаковое число (int), для получения фактического значения необходимо три угла Roll, Pitch, Yaw разделить на 10. Например, если значение, считанное из модуля, равно 1508, то фактическое значение равно 1508/10=150,8°. Поскольку фактическое значение является плавающей точкой (float), то при применении необходимо преобразовать тип данных. Аналогично, трехосное ускорение делится на 100, а трехосная угловая скорость делится на 10, чтобы получить фактическое значение. <u>Например</u>, если значение ускорения по оси Z равно 103, то фактическое значение равно 103/100 = 1,03g; если значение угловой скорости X равно 2506, то фактическое значение равно 2506/10 = 250,6°/с.

# 7. Обновление версии прошивки датчика

13 августа 2021 г. В прошивках версий 11039 и 11041 поменяны местами оси X и Y, что привело к увеличению диапазона измерения крена и уменьшению диапазона измерения угла продольного наклона; пользователи могут обновлять прошивку по мере необходимости.
